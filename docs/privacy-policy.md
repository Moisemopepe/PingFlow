# PingFlow Privacy Policy

Effective date: May 3, 2026

PingFlow is a network diagnostic application that helps users test connectivity, latency, routing, and connection speed.

## Data processed by the app

PingFlow may process the following technical data only to provide network diagnostic features:

- Domains or IP addresses entered by the user for ping and traceroute tests.
- Network diagnostic results, such as latency, route hops, speed test results, and backend availability.
- Public IP address lookup results used to display network information.
- Local app settings, such as theme and language preferences.
- Local diagnostic history saved on the user's device.

PingFlow does not sell personal data. PingFlow does not use advertising SDKs.

## Backend and third-party services

Some diagnostics are processed through the PingFlow backend API. When a user starts a diagnostic test, the entered domain or IP address may be sent to the backend so the requested test can run.

PingFlow may use a public IP lookup service to display the device's public IP address.

## Local storage

Diagnostic history and app settings are stored locally on the user's device. Users can clear diagnostic history from the app.

## Feedback

The app may include a feedback form. In the current version, feedback is handled locally in the app and is not submitted to a server.

## Data sharing

PingFlow does not sell user data and does not share user data for advertising. Technical data may be transmitted to the PingFlow backend only when required to provide diagnostic features requested by the user.

## Security

PingFlow uses HTTPS for production backend communication where available.
